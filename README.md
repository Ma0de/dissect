# dissect
针对 renpy 开发的可视化解包工具

## 特性

它能给你提供一个可视化的网页界面，然后你可以在上面进行操作

有 剧情文案、选项分支、流程图、字段、资源、头文件 这几个功能

为了方便找音频文件，还写了一个给台词和音频文件建立映射的功能，当一个文案识别到有音频时你可以在台词下面看到一个“试听”

在 0.5.0 版本中，引入了将 Ren'Py 8.x Windows 版游戏转换为 Web 版的功能

## Game for Web

把 Ren'Py 8.x 游戏在本地转换成浏览器可运行的 Web 版（WebAssembly），可以直接试玩；
也可以导出成不依赖 dissect 的静态站点（目录或 ZIP），上传到任意静态 HTTP 服务器或
静态托管平台就能对外提供，导出包内附部署说明。
